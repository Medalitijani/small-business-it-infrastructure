# Small Business IT Infrastructure

Designing and building the IT environment of a 20-person company from scratch: network, Active Directory, PowerShell automation and documentation.

## Overview

This project simulates the IT setup of a small company with three departments (Staff, Management, IT). I designed the network, built a Windows domain, applied Group Policies, and documented the procedures.

## Phases

| Phase | Description | Status |
|---|---|---|
| [1. Network design](01-network) | VLANs, inter-VLAN routing, DHCP, guest isolation (Cisco Packet Tracer) | 🔄 In progress |
| [2. Active Directory](02-active-directory) | Windows Server domain, users, groups, Group Policies | ✅ Done |
| [3. PowerShell automation](03-powershell) | Scripts for user creation, inventory and disk checks | ⏳ Planned |
| [4. Support documentation](04-documentation) | Helpdesk guide, onboarding checklist, backup procedure | ⏳ Planned |

## Skills used

- **Networking:** VLANs, DHCP, inter-VLAN routing, access control lists
- **Systems:** Windows Server, Active Directory, Group Policy
