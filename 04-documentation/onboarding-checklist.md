# New employee onboarding checklist

Use one copy per new employee. Tick each item when done.

**Employee:** ____________  **Department:** Staff / Management / IT  **Start date:** ____________

## Before day 1

- [ ] Get the request and approval from the manager (name, department, start date, access needed).
- [ ] Create the Active Directory account in the right OU (Staff, Management or IT).
- [ ] Add the user to the matching group (GG_Staff, GG_Management or GG_IT).
- [ ] Set a temporary password and force a change at first logon.
- [ ] Create the email mailbox / Microsoft 365 license.
- [ ] Prepare the workstation: install Windows updates, standard software, and antivirus.
- [ ] Join the PC to the domain `company.local` and check that Group Policies apply.
- [ ] Assign the right network: Staff VLAN 10, Management VLAN 20 (guests never use internal VLANs).

## Day 1

- [ ] Hand over the PC, accessories and the temporary password in person.
- [ ] Log in together and set the new password.
- [ ] Check email, shared folders and printers.
- [ ] Explain security basics: strong passwords, no password sharing, locking the screen, and reporting suspicious emails.
- [ ] Show how to contact IT support.

## First week

- [ ] Check that everything works and fix open issues.
- [ ] Add the equipment to the inventory.

## Offboarding (when someone leaves)

- [ ] Disable the account (do not delete it right away).
- [ ] Reset the password and remove group memberships.
- [ ] Back up the user's data and mailbox, then transfer them to the manager according to company policy.
- [ ] Collect the equipment and securely wipe it before reassignment.
