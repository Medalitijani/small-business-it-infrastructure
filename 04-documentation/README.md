# Phase 4 — IT Support Documentation

This phase contains practical procedures for common small-business IT support tasks.

## Documents

- [Helpdesk troubleshooting guide](helpdesk-guide.md) — step-by-step checks for common Windows, network, email, printer, and security incidents, plus a ticket template.
- [New employee onboarding checklist](onboarding-checklist.md) — account setup, workstation preparation, first-day checks, and offboarding.
- [Backup procedure](backup-procedure.md) — 3-2-1 backup principle, suggested schedule, Windows Robocopy example, restore testing, and ransomware precautions.

## Skills demonstrated

- Incident troubleshooting and documentation.
- User onboarding and offboarding.
- Basic backup planning and restore validation.
- Clear, repeatable IT procedures for a small business.
